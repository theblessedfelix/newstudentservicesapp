
  # New Student Services App

  This is a code bundle for UI Design Focus. The original project is available at https://www.figma.com/design/pgVBGi4cHubgEbKwlVPbhC/UI-Design-Focus.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Once the server is running, open your browser and navigate to:

  - **Main app (volunteer/public portal):** http://localhost:5173/
  - **Admin portal:** http://localhost:5173/admin/

  ## Previewing the production build

  Run `npm run build` to create a production build in the `dist/` directory.

  Run `npm run preview` to serve the production build locally and preview it before deploying.

  Once the preview server is running, open your browser and navigate to:

  - **Main app (volunteer/public portal):** http://localhost:4173/
  - **Admin portal:** http://localhost:4173/admin/
